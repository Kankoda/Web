Kankoda has released a brand new SDK called [{{sdk.name}}]({{sdk.url}}), which brings Vietnamese input support with TELEX, VNI & VIQR to all Apple platforms.

![Blog post header]({{page.image}})

{{sdk.name}} has been extracted from [KeyboardKit Pro](https://keyboardkit.com)'s Vietnamese typing support, and has improved the input logic a great deal.

The SDK has an input engine that lets you type a sequence of characters into a string, using any of the three main input methods - TELEX, VNI & VIQR - without switching to a Vietnamese keyboard.

{{sdk.name}} works on iOS, iPadOS, macOS, tvOS, visionOS, and watchOS, and can be used in both apps and SDKs.
