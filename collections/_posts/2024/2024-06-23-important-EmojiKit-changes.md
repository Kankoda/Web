After not being able to scale EmojiKit Pro to a commercial product, Kankoda will migrate EmojiKit back to an open-source library.

![EmojiKit header]({{page.image}})

This will affect the [EmojiKit GitHub project](https://github.com/danielsaidi/emojipicker), which has been transferred to [the founder's personal GitHub account](https://github.com/danielsaidi). It will from now on be listed together with his other [open-source projects](https://danielsaidi.com/opensource).

This also affects the Gumroad product, which has been deleted, as well as all EmojiKit-related pages on this website.
